Release Report (v2.2.0)

1막 시작 덱 축소 및 빈 슬롯 시스템 보고서

오토 배틀러 밸런싱 최적화 및 덱 압축 성장 모델 검증 완료

핵심 시스템 구현 스펙

  • 그리드 명시적 빈 슬롯 사전 할당 (CardSystem.js) 덱 드로우 전에 그리드를 항상 16개의 고정 EMPTY 객체로 사전 할당합니다. 덱에서 드로우된 카드들이 0번부터 순차적으로 이 슬롯을 덮어쓰게 됩니다. 덱 크기가 16장 미만인 경우 남은 자리는 점선 격자의 빈 슬롯(EMPTY) 상태로 유지됩니다.
  • 빈 슬롯 빙고 제외 및 딜레이 유지 (GameEngine.js) 빙고 검사 루프에서 EMPTY 타입 카드가 하나라도 섞인 라인은 즉시 판정에서 스킵합니다. 단, 자동 턴 루프 순차 발동 시에는 딜레이(150ms)와 하이라이트 애니메이션을 그대로 유지하도록 설계하여 플레이어가 상황을 인지하고 아이템(포션)을 쓸 수 있는 조작 반응 시간을 충분히 벌어줍니다.
  • 그리드 조작 예외 및 덱 오염 필터링 완료 SWAP(위치 교환)을 제외한 TRANSFORM, REPLACE, UPGRADE 조작이 빈 카드를 대상으로 오작동하지 않게 차단했습니다. 또한, 턴 종료 시 임시 EMPTY 카드들이 버린 카드 더미로 유입되어 전체 덱에 증식 누적되던 현상을 discardGrid()와 getAllCards() 필터링을 통해 원천적으로 해결했습니다.
  • 카드당 턴당 빙고 참여 제한 (Bingo Limit) 특정 강화 카드 하나를 연쇄 SWAP하여 빙고를 무한 기여시키는 무한 루프 버그를 차단하기 위해, 각 카드 인스턴스별로 한 턴 동안 최대로 빙고 발동에 관여할 수 있는 기여 한도(maxCardBingoContribPerTurn: 4) 제약을 연동했습니다.
  • 릴리즈 파이프라인 자동화 (npm run release) 플랫폼에 독립적으로 윈도우 및 리눅스 셸에서 원클릭으로 작동하는 scripts/release.js 파이프라인을 기획하여 git add . ➔ commit ➔ push ➔ gh-pages 배포 단계를 동기적으로 자동화하였습니다.
